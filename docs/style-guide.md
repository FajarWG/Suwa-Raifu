# STYLE GUIDE

## Suwa Life: Nihongo Days

**Versi:** 0.1
**Status:** Draft

---

## 1. Art style

- **Colorful semi-low-poly** (PRD §24).
- Bentuk geometris sederhana, warna cerah, proporsi karakter Roblox default.
- Suasana tenang: nuansa pagi hangat, danau biru, pegunungan hijau.

## 2. Palet

| Peran | Warna (hex) | Catatan |
|---|---|---|
| Primary (danau) | `#3B82C4` | Air, langit |
| Secondary (alam) | `#7FB069` | Pohon, bukit |
| Warm (sekolah) | `#E8A54A` | Gedung, lampu |
| Accent (festival) | `#E05D5D` | Payung, stall, kembang api |
| Netral | `#F4F1EA` / `#2F2A26` | Dinding / bayangan |
| Malam | `#1C2541` + lampu hangat | Day/night |

## 3. Skala

- Karakter: default Roblox R15 (4 stud = 1 m).
- Pintu: 4 × 8 stud.
- Jalan: 8–12 stud.
- Bangunan: 70–90% ukuran realistis (PRD §8).
- Jarak: 1:4–1:8 terhadap lokasi asli.

## 4. Material palette

- Jalan: asphalt (Gravel/Slate) + trotoar (Concrete).
- Bangunan: Wood / Brick / Glass dengan warna solid.
- Danau: Smooth plastic biru dengan transparansi ringan.
- Gunung: rock texture + pohon Pine/Leafy.

## 5. Properti & prop

- Prop modular: 1 grid unit = 4 stud.
- Semua prop harus punya collision sederhana (bagian collision > visual untuk performance).
- NPC: ukuran konsisten, skin/tone beragam (negara asal pemain).

## 6. UI

- Font: bahasa dengan furigana (support) — gunakan Font Builder font yang konsisten.
- Warna UI mengikuti palet; aksen hijau untuk sukses, merah untuk error.
- Kontras minimal WCAG AA; indikator tidak bergantung warna saja (PRD §15).

## 7. Audio

- Musik santai (loop), volume terpisah untuk kembang api (PRD §15).
- SFX: sepeda bell, uang, ikan, stamp, dialog.

## 8. Checklist review aset

- [ ] Ukuran & skala sesuai standar di atas.
- [ ] Collision benar (bukan block besar).
- [ ] Triangle count wajar untuk mobile.
- [ ] Material & palet sesuai.
- [ ] Hak penggunaan aman (tidak ada logo/merek/orang nyata).
- [ ] Performa diuji mobile.
